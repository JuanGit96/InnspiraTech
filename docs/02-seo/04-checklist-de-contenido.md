# Checklist antes de publicar

Vale para un artículo del blog, una página de servicio o cualquier texto nuevo
del sitio. Son diez minutos que evitan la mayoría de los problemas.

## Antes de escribir

- [ ] ¿Qué búsqueda ataca este contenido? Escríbela tal cual la haría un cliente.
- [ ] ¿Hay ya una página nuestra compitiendo por esa misma búsqueda? Si la hay,
      mejor actualizarla que publicar una nueva.
- [ ] ¿Qué servicio resuelve el problema del que habla? Ese será el enlace final.
- [ ] ¿Cuál es la intención: decisión, comparación o descubrimiento?

## Estructura

- [ ] El título contiene la búsqueda y cabe completo en el resultado de Google
      (unos 60 caracteres el título SEO).
- [ ] La URL es corta, en minúsculas, sin fechas ni números.
- [ ] Un solo H1. Los H2 están escritos como preguntas o afirmaciones concretas.
- [ ] La primera frase después de cada subtítulo **responde**; el desarrollo va
      después. Es lo que permite que un modelo de IA cite el fragmento.
- [ ] Hay al menos una tabla o lista comparable cuando el tema implica elegir.
- [ ] Hay preguntas frecuentes al final, con las dudas reales del área comercial.

## Enlaces

- [ ] Enlaza a su servicio relacionado.
- [ ] Enlaza a dos o tres artículos del mismo grupo temático.
- [ ] Tiene el campo «Servicio relacionado» completo (hace que aparezca en la
      ficha de ese servicio).
- [ ] Ningún enlace apunta a un artículo que ya está publicado y luego se
      despublicó.

## SEO en el admin

- [ ] Título SEO ≤ 60 caracteres.
- [ ] Meta descripción ≤ 155 caracteres, con beneficio y llamada a entrar.
- [ ] Extracto escrito a mano (se usa como entradilla y en `/llms.txt`).
- [ ] Imagen destacada 1200×675 con texto alternativo descriptivo.
- [ ] Categoría correcta; etiquetas solo si aportan.

## Honestidad

- [ ] Ninguna cifra inventada. Si es un rango, se dice de qué depende.
- [ ] Ningún caso de cliente con nombre sin permiso por escrito.
- [ ] Ninguna promesa que no podamos cumplir o medir.
- [ ] Las afirmaciones legales o normativas remiten a revisar con un asesor.

## Antes de dar a publicar

- [ ] Leído en voz alta una vez: si hay que releer una frase, se reescribe.
- [ ] Revisado en móvil.
- [ ] Fecha de publicación correcta (ojo con el calendario programado).
- [ ] Si el artículo reemplaza o canibaliza a otro, decidir cuál se queda y
      redirigir el otro.
